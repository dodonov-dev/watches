When asked to make a preset, create a distinct look of my own (different liquid, backing, marks) — not a
tweak of the user's shared configs. Presets are meant to differ from each other (alpine was well received).

**Why:** 2026-09-23 I delivered `lime-soda` as a light edit of the user's `perfect_buble_config.json`; the user
said "your preset doesn't have to be based on mine … that's the idea of presets — they can be different".

**How to apply:** use the user's configs to learn which current render settings look good (glass, meniscus,
lens, fizz), then pick a new liquid/vessel concept and verify frames with [[run-sim]] shots. See
[[params-mirror-firmware]] only if Params keys change (a new preset alone doesn't).
